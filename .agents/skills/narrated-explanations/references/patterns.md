# Choosing a visual pattern

| Pattern | Use when | Motion and narration | Avoid |
|---|---|---|---|
| Draw toward an event | Order and elapsed time explain the result | Add the labeled marker immediately; draw the trace to its endpoint over the clip. Narrate either the absolute time or a meaningful interval. | Pretending sub-second events are distinguishable on a long time axis. Add a zoom/inset when needed. |
| Locate → interpret → conclude | A source supports a conclusion | Show unhighlighted context; highlight the finding; update its implication on a persistent map. The middle beat explains, not reads. | Revealing the verdict in the title before orienting the viewer; treating a green status badge as definitive evidence. |
| Persistent path | The audience must locate causes along a process | Reuse node positions. Move the emphasis, not the diagram. | Reordering nodes between evidence and verdict or forcing a linear path onto a branching system. |
| Accumulating verdict | Candidates are resolved one at a time | Keep prior decisions subdued; cross out or confirm the current candidate. State uncertainty explicitly. | Treating absence of evidence as proof, or using color as the only status cue. |
| Same input, different outcome | One changed variable explains a difference | Align axes and units or apply the same schematic burst to both capacities. Narrate what stayed constant and what changed. | Implying causal isolation when other variables changed; presenting schematic motion as measured data. |
| Anchor caption | Narration needs to direct attention | Name the region, timestamp or object in a short phrase. Offer full captions independently. | Showing a paragraph that competes with the narration. |

Use motion selectively. An 18-second interpretation can hold one highlighted line still; it does not need 18 seconds of decorative animation. A ring-buffer simulation illustrates arrivals, capacity and draining; it is not a general model of every queueing system.

The current library provides event metrics, a linear path diagram, staged evidence, an overlaid comparison chart and schematic buffers. Adapt the data and labels. Use a custom visual when those primitives do not fit the explanation.
